# Firewall Exploration Lab

## Project Overview

The Firewall Exploration Lab was a cybersecurity project that gave me hands-on experience with how firewalls inspect, filter, and control network traffic. I worked in a Linux and Docker environment and explored different methods of packet filtering using Netfilter and iptables.

## What I Did

During the lab, I worked with Linux kernel modules and Netfilter to intercept and examine network packets. I analyzed different types of traffic including TCP, UDP, ICMP, and DNS traffic to understand how firewall rules affect network communication.

I also created and tested firewall rules using iptables. I worked with INPUT, OUTPUT, and FORWARD rules and tested how different configurations affected traffic such as ping requests, DNS queries, and TCP connections.

The lab also introduced me to stateless and stateful packet filtering. I used connection tracking to examine active network connections and worked with rate limiting to control the amount of traffic allowed through the firewall.

I verified firewall behavior by testing network communication between Docker containers and examining system and kernel logs.

This project helped me better understand how firewall rules are used to control network traffic and protect systems. I gained hands-on experience working with Linux firewall tools and learned the differences between stateful and stateless packet filtering.

The lab also helped me understand how traffic can be monitored, blocked, or allowed based on protocols, connections, and firewall rules.
